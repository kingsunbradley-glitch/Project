#  DSSD_recal_all 参考峰表
#  --------------------------------------------------------------------------
#  本文件取代了过去写死在 Config.h 里的 REF_PEAKS / DIAG_PEAKS。
#  换实验（换束流、换靶轮、换探测器）时只改这里，不需要重新编译。
#
#  格式：每行  "<能量 keV>  <搜索半窗 keV>"
#        以 # 开头的是注释，空行忽略；[节名] 切换后面的峰属于哪一类。
#
#  [ref]   参与平面绝对刻度 (K,B) 的参考峰。
#          Step 2 对每个面用这些峰做 pol1 拟合；至少需要 REF_MIN_POINTS 个
#          被成功定位的峰、且能量跨度不小于 REF_MIN_SPAN_KEV，否则该面刻度
#          被否决，并沿用 X 面（见日志里的 [FALLBACK] / [INHERIT]）。
#          峰间隔决定斜率的精度：两点相隔 Δ 时增益误差约 sqrt(2)*dE/Δ。
#          这里 8783 与 7065/7128 跨 1718 keV，而 7065 与 7128 只差 63 keV
#          （谱线 FWHM 已 30 keV 量级），后者单独没有杠杆，实测这两个点给出
#          的局域增益比全局值低 3.2%，是 6 MeV 处约 ±9 keV 系统误差的来源。
#
#  [diag]  只用于刻度后的验收，不参与拟合。残差会写进 peaks_list.txt 的
#          "--- <面> Absolute Scale ---" 段，并汇总成 diag rms。
#          6113 / 7686 / 5304 是三条 α 线，故意留在 [ref] 外面，这样它们
#          对刻度是独立检验而不是自我实现。
#
#  [strip] 逐条一致性检查用的峰（Step 2 输出表里的 FWHM / dE 两列）：
#          能量和搜索半窗。只有第一行有效；缺这一节时用 Config.h 的
#          target_E / fit_win。
# ==========================================================================
