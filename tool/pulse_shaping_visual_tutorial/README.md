# 梯形、三角与 RCCR（RC–CR）脉冲成形：图像教程

这套小教程从核探测器前放脉冲出发，用动画解释三种输入情况和三种常见数字成形算法。

## 动画 0：正常脉冲、高频噪声与低频噪声

![正常脉冲、高频正弦噪声和低频正弦噪声](animations/00_三种输入信号演示.gif)

三行使用完全相同的脉冲、纵轴和噪声振幅：

1. 正常信号具有有限的快速上升时间，随后按较慢的时间常数逐渐衰减。
2. 第二行叠加振幅 `0.08`、频率 `0.80 MHz` 的正弦噪声，表现为密集快速抖动。
3. 第三行叠加相同振幅、频率 `0.04 MHz` 的正弦噪声，表现为缓慢的基线起伏。

动画参数只是为了清楚展示两种频率成分，不代表某一块具体采集卡的固定噪声频谱。

## 动画 3：三种输入分别经过三种算法

![三种输入经过梯形、三角和RCCR成形](animations/03_三种输入经过三种成形算法.gif)

这张动态矩阵的三列分别是正常脉冲、高频正弦噪声脉冲和低频正弦噪声脉冲；四行依次是原始输入、梯形成形、三角成形和 RCCR 成形。处理约定如下：

- 三种输入都先用相同的 `τd=22 μs` 做极零相消，再进入成形器。
- 梯形使用 `L=8 μs, G=4 μs`；三角使用 `L=8 μs, G=0`；RCCR 使用 `τCR=τRC=5 μs`。
- 三列输出统一除以正常信号的峰值，而不是各自单独归一化，所以噪声残留和峰值偏差不会被视觉缩放掩盖。

## 0. 共同起点：前放脉冲不是我们最后想测的形状

电荷灵敏前放常给出“快速上升、指数衰减”的波形。脉冲高度与沉积能量有关，但长尾会造成基线漂移和脉冲堆积。图中先用已知前放衰减常数做**极零相消（pole-zero cancellation）**，把指数长尾校正成等幅阶跃，再交给成形器。

理想指数衰减可写成

\[
x[n] \propto p^{n-n_0},\qquad p=e^{-\Delta t/\tau_p}.
\]

脚本先求“去极点后的冲量”

\[
q[n]=x[n]-p\,x[n-1],
\]

再累加得到阶跃。实际实验中，`τp` 估错会让成形脉冲出现上翘或下垂。

## 1. 梯形算法：两个移动平均窗相减

先定义长度为 `L` 的因果滑动平均：

\[
M_L[n]=\frac{1}{L}\sum_{i=0}^{L-1}s[n-i].
\]

把它减去一个延迟 `L+G` 个采样点的副本：

\[
y_{trap}[n]=M_L[n]-M_L[n-(L+G)].
\]

阶跃进入第一个窗口时，输出线性上升；第一个窗口完全装满而第二个还没碰到阶跃时，输出形成宽度为 `G` 的平顶；第二个窗口随后装满，输出线性下降。

![梯形与三角窗口相减原理](figures/01_梯形与三角_窗口相减.png)

怎么读这张图：

1. A 图的蓝线和橙线分别是当前滑动平均及其延迟副本，二者的竖直差就是成形输出。
2. B 图中 `L` 决定上升和下降时间，`G` 决定平顶宽度。
3. 能量通常在平顶中间取样，或对平顶若干点求平均。平顶能容纳一定的电荷收集时间变化，因此较不容易产生弹道亏损。

## 2. 三角算法：把梯形的平顶压到零

令 `G=0`：

\[
y_{tri}[n]=M_L[n]-M_L[n-L].
\]

此时上升斜坡和下降斜坡直接相接，梯形自然退化成三角形。它不是另一套神秘公式，而是梯形成形的特殊情况。

- 优点：结构简单；在相同 `L` 下脉冲持续时间较短，较利于高计数率。
- 代价：没有平顶，峰值对电荷收集时间变化和峰位寻找误差更敏感。
- 读数：取尖顶附近的最大值，并在能量标定时保持同一组 `L`。

## 3. RCCR：这里指 RC–CR 成形

“RCCR”在这里按核电子学中常见的 **RC–CR** 成形理解。CR 是高通/微分环节，RC 是低通/积分环节。对理想线性时不变系统，两级串联的乘法次序可以交换；数字实现通常按便于计算的顺序级联。

![RC-CR 两级各自的作用](figures/02_RCCR_RC-CR_两级作用.png)

脚本采用一阶递推：

\[
d[n]=a\{d[n-1]+x[n]-x[n-1]\},\qquad
a=\frac{\tau_{CR}}{\tau_{CR}+\Delta t},
\]

\[
y[n]=y[n-1]+b\{d[n]-y[n-1]\},\qquad
b=\frac{\Delta t}{\tau_{RC}+\Delta t}.
\]

CR 让恒定阶跃最终回到零，从而抑制直流和慢基线；RC 把尖锐变化摊开，从而压低高频噪声。当 `τCR=τRC=τ` 时，连续时间下的阶跃响应形状为

\[
y(t)\propto \frac{t}{\tau}e^{-t/\tau},
\]

因此峰值大约出现在阶跃后 `1τ`。它常被称为一阶半高斯成形；继续串联更多 RC 级会得到更接近高斯的 `CR–RCⁿ` 成形。

## 4. 参数变化：更宽不等于总是更好

![三种成形参数对波形的影响](figures/03_参数如何改变波形.png)

| 算法 | 主要参数 | 参数增大后 | 更适合关注 |
|---|---|---|---|
| 梯形 | 上升长度 `L`、平顶 `G` | 平均更充分、平顶更宽，但脉冲更长 | 稳定能量测量、电荷收集时间有变化 |
| 三角 | 成形长度 `L` | 噪声通常减小，但脉冲更宽、堆积更多 | 简单快速、高计数率下的折中 |
| RC–CR | `τCR`、`τRC` | 波形更平滑、更宽，峰位更晚 | 模拟成形直觉、基线与高频噪声折中 |

实际选择的核心矛盾是：**更长的成形时间通常能降低一部分噪声，却会增加相邻脉冲堆积的概率。** 最优参数应使用真实基线噪声、真实上升时间分布和目标计数率扫描，而不是只看一条理想波形。

## 5. 三句话记忆

1. **梯形**：两个错开的矩形平均窗相减，平顶让能量读数更稳。
2. **三角**：就是 `G=0` 的梯形，结构简单、没有平顶缓冲。
3. **RC–CR**：CR 去慢变化，RC 去快噪声，合起来得到圆滑单峰。

## 6. 重新生成图片

需要 Python 3、NumPy 和 Matplotlib。在仓库根目录运行：

```bash
python3 tool/pulse_shaping_visual_tutorial/generate_figures.py
```
