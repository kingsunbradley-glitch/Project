# 半衰期与 0.68 C.L. 统计误差

将实验数据填入脚本同目录的 `input.dat`，每行一个正的衰变时间差，
所有时间采用相同单位。支持科学计数法、Fortran `D` 指数、空行及 `#` 注释。
输入为逐事件时间差，不是绝对时间戳或直方图计数。
附带的 `input.dat` 只有格式说明，未填入虚构的实验数据。

```bash
python3 /home/evalie/Project/Function/Project/tool/calcHalfLife/calc_half_life.py --unit ms
```

无论从哪个目录启动，默认均读取脚本同目录的 `input.dat`。
可用 `--input /absolute/path/input.dat` 指定其他文件。
`--unit` 仅设置输出单位标签，不对数值换算。
程序输出事件数、所用方法、平均寿命、半衰期、上下置信限及非对称误差，
不改写输入文件，不自动保存或覆盖结果表。仅需 Python 3.8+ 标准库。

## 文献与方法

K.-H. Schmidt, C.-C. Sahm, K. Pielenz, H.-G. Clerc,
*Some remarks on the error analysis in the case of poor statistics*,
Z. Phys. A **316**, 19–26 (1984),
[DOI: 10.1007/BF01415656](https://doi.org/10.1007/BF01415656)。
已核对用户指定 PDF 的第 4 节、第 7 节及表 1。

按用户确认的边界，`1 <= N < 21` 使用定义法，`N >= 21` 使用极大似然法。
两分支的点估计均采用论文式 (15)：

```text
tau_hat = sum(t_i) / N
T_hat   = ln(2) * tau_hat
```

它们的差别在于置信区间的构造。计算半衰期上下限时，对寿命上下限同乘 `ln(2)`；
最终报告 `T_hat + (T_upper-T_hat) - (T_hat-T_lower)`。

### N < 21：式 (17) 的精确中心置信区间

论文第 4 节式 (9) 定义中心区间，第 7 节式 (16)–(17) 给出寿命对应的分布及求解方程。
令 `S=sum(t_i)`、`x=S/tau`，则 `x` 服从形状参数为 `N` 的单位尺度 Gamma 分布。
其上尾概率为

```text
Q_N(x) = exp(-x) * sum(x**k/k!, k=0,...,N-1)
Q_N(S/tau_lower) = 0.16
Q_N(S/tau_upper) = 0.84
```

脚本直接求解有限和方程，不采用式 (18) 的近似式，也不对似然函数作贝叶斯归一化。
等价表达是 `tau_lower=2*S/chi2_ppf(0.84,2*N)`、
`tau_upper=2*S/chi2_ppf(0.16,2*N)`，运行时不需要 SciPy。

当 `N=1`、`tau_hat=1` 时，恰好 0.68 C.L. 给出约 `[0.545678, 5.735478]`。
原文把高斯 `z=1` 的约 0.682689 C.L. 简记为 0.68，表 1 因而给出约
`[0.543, 5.79]`。脚本按用户要求采用恰好 `0.68`，不直接抄录表中舍入值。

### N >= 21：极大似然与似然比区间

采用指数分布的无分箱似然函数，点估计仍为式 (15)。
令 `r=tau/tau_hat`，通过数值求根确定上下界：

```text
ln L_max - ln L(tau) = N * (ln(r) + 1/r - 1) = z**2/2
z = 标准正态分布的 0.84 分位数
```

阈值约为 `0.49447324`。常用的 `Delta ln L=0.5` 对应约 0.682689 的渐近 C.L.。
这里是按恰好 0.68 标定的一参数渐近似然比区间，有限样本实际覆盖率未必恰为 0.68。
大样本分支及 21 个事件的切换是按用户要求设置的；原文式 (17) 本身不受该事件数限制。

## 适用范围

假设单一核素、独立的指数衰变时间，且无背景、无观测时间窗截断及删失。
若实验有这些效应，应使用包含相应效应的似然函数。
输出误差是衰变事件的统计误差；仪器时间分辨率等系统误差需要另外提供信息。
零或负时间、NaN、无穷、空数据及多列数据均会报错，不会静默丢弃。
