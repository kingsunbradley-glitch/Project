## 模型条件

GSI 对不同背景类别的总率只求和一次，并在链序列中将 alpha23 引用两次。
相邻链成员间不允许出现其他所列候选类别事件。
不含 SF 的版本中，SF 不作为该链的候选类别计入总率；含 SF 时重算包含 SF 的总率及全部指数项。

Lazarev 尚未提供实测相邻配对数。本次采用前次的均匀率估计，含 SF 时的配对期望数为
1.264862321、62.861366877、151.554491154、192.868940834；分母依次是 61470、148200、148200。
因此该行与低率式一致，不构成基于另一份实测配对数据的独立结果。

Berkeley 使用每个相邻窗口内至少一次的乘积。alpha2 和 alpha3 在各自窗口中分别使用
148200 的计数，不平分、不相加；不是在单一宽总窗里数三个 alpha。

Dubna 按 ER 锚定的固定最大总跨度内恰好出现所列各类个数计算，再显式乘以全部相邻时间门的
条件时间接受度。其扩展额外要求总窗内无其他所列衰变类别事件，但允许额外 ER。
不含 SF 时总跨度为 200.1 s，含 SF 为 300.1 s；均使用同类 alpha23 的 K=2 计数。
这是对原始计数式添加时间选择的扩展，未把未经逐级筛选的宽总窗概率当作用户的搜索结果。

实际 Monte Carlo 插入法仍缺事件列表或插入/命中统计；Dubna 其他时间、寿命、位置检验缺实际链数据。
所有结果仍假设共用曝光、均匀位置背景及互不重叠的 ER、alpha1、alpha23、SF 类别，未传播背景率估计误差。
