# 逐跃迁数据库与各公式 HF—结构标签范围

## 1. 研究范围与交付

覆盖 \(Z=89–118\)、截至 2026 年 10 月 22 日公开的 α 跃迁，包含基态、激发态及同核异能态。

交付本地离线交互页面、SQLite/CSV 数据库、可复现代码和导出图。最终核心结果是：**每套公式分别给出下面七类标签对应的 HF 经验范围、样本量和证据，支持查看范围内的具体跃迁。**

## 2. 数据与计算

- 以 ENSDF、质量与核性质评估及原始实验论文建立逐跃迁记录，交叉核对已有 `HFdistr` 数据。
- 保存初末态尼尔森轨道、\(Q_{if}\)、\(J_i^\pi,J_f^\pi\)、实验半衰期、分支比、不确定度、组态及文献依据。区分基态质量差与跃迁 Q 值、总 α 分支与单条 α 线强度。
- 使用 Royer、DZR、Ismail2022 Formula E、Qi2009 UDL、Viola–Seaborg、Xu2022、E. Rurarz，排除 `PoenaruMethod.py`。保留本地原版；有原文依据的核正版另列，不重新拟合。
- 按选择定则求最小允许角动量：
  \[
  l_{\min}=\min\{l\in\mathbb Z_{\ge0}:|J_i-J_f|\le l\le J_i+J_f,\ 
  (-1)^l=\pi_i\pi_f\}.
  \]
- 含角动量项的公式同时输出
  \[
  HF_m^{(0)}=\frac{T_{if}^{\rm exp}}{T_m(0)},\qquad
  HF_m^{(l_{\min})}=\frac{T_{if}^{\rm exp}}{T_m(l_{\min})}.
  \]
  无显式角动量项的公式输出原式 HF，\(l_{\min}\) 列标记“不适用”。不允许的 \(l=0\) 明确标为形式参考。
- 候选自旋宇称分别计算；未知值、上下限和未分辨跃迁保留状态标记，不默认补成确定值。实验误差与公式系统偏差分别记录。

## 3. 七类标签及 HF 范围

| 标签 | 解释与判定依据 |
|---|---|
| `same_intrinsic` | 初末态具有相同内禀准粒子组态 |
| `same_band` | 母子核中对应的同组态转动带相关成员 |
| `nilsson_changed` | 有依据的 Nilsson 轨道改变，保存改变前后的轨道指认 |
| `multi_qp_changed` | 多准粒子组态改变，保存可辨认的组态组成变化 |
| `shape_changed` | 有独立证据支持的形变变化 |
| `configuration_mixing` | 有证据支持明显组态混合，保存混合组态及已知混合程度 |
| `parity change` | 初末态宇称发生变化 |
|   `spin flip` | 初末态自选发生变化，自选定义为$\Lambda - K$
| `unknown` | 证据不足，无法可靠归入前六类 |

前六类允许同时出现；`unknown` 用于没有可靠结构标签的跃迁。每个标签保存来源及证据等级，不能仅凭 HF 大小赋标签，再用这些标签标定 HF。

**每个“公式 × 版本 × 标签”分别建立范围表：**

| 输出字段 | 含义 |
|---|---|
| HF 中位数 | 该标签样本的典型水平 |
| 主要经验范围 | 第 10–90 百分位，覆盖中间 80% 的样本 |
| 全部样本跨度 | 最小值至最大值，并可追溯端点对应跃迁 |
| 样本量 | 跃迁数、不同母核数 |
| 范围不确定度 | 按衰变链分组重采样得到的统计区间 |
| 证据与适用范围 | 证据等级、核区、核子奇偶类别、角动量处理方式 |

具体规则：

- \(HF^{(0)}\) 与 \(HF^{(l_{\min})}\) **分别统计范围**，不混在一起；各公式、各参数版本也分别统计。
- 主标定采用独立谱学证据及可确定的跃迁数据；暂定指认、HF 推定组态、上下限和估算 Q 值作为单独可切换的数据层。
- 默认合并全区展示，同时提供核区及偶偶、偶奇、奇偶、奇奇筛选。
- 少于 10 个不同母核的类别标记“小样本”：展示具体数值与样本跨度，不作为稳定判别范围；无数据时显示“暂无可标定数据”。
- `unknown` 展示其观测 HF 分布，但不把该分布当作一种结构变化的判据。
- 范围重叠时如实显示。给定某个 HF，可以返回与它相容的多个标签及支持样本，不强行唯一分类。

## 4. 离线可视化

页面采用内嵌数据和资源的 HTML/JavaScript，双击即可使用，包含四个联动视图：

- **核素图与跃迁表**：筛选核区、初末态、公式、标签、证据和数据质量；同一核素的多条跃迁分别保留。
- **HF—标签范围图**：七类标签逐行排列，显示散点、中位数、主要经验范围及全部跨度；支持公式并排比较。
- **角动量对照图**：连接同一跃迁的 \(HF^{(0)}\) 与 \(HF^{(l_{\min})}\)，显示误差及修正幅度。
- **跃迁详情**：展示“初态组态 → 末态组态”、结构标签、原始数据、计算结果、文献证据和替代解释。

范围图可点击展开构成该范围的全部跃迁；提供公式、角动量处理和原版／核正版切换。支持导出当前筛选数据、范围汇总表、SVG/PNG 图和完整数据库。

## 5. 验证与验收

- 验证分支归一化、部分半衰期、单位和 Q 值处理，避免重复修正。
- 检查自旋宇称选择定则，包括无允许角动量的情况。
- 对本地公式做数值回归，对核正版核对原论文。
- 核查标签证据的独立性，确认多标签样本不会被误当作独立重复观测。
- 验证统计表、范围图、详情和导出数据一致，页面断网可用。
- 最终提供七套公式对应七类标签的完整汇总；每个范围均可追溯到具体跃迁，缺失范围均说明原因。
